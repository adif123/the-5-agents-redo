# גיא — שומר הסף האחרון (QA)

> Pointer doc לבני אדם. המקור הקנוני: [`.claude/agents/guy.md`](../.claude/agents/guy.md).

## מי גיא

הסוכן ה-5 והאחרון בשרשרת. רץ אחרי שיעל מסיימת. בודק את התוצר מול הבריף + מדריך הסגנון + שלמות מבנית + תמונות + שלמות טכנית. מפיק דוח QA מובנה. **הסוכן היחיד שמורשה לדחות תוצר.**

## כלים

`Read`, `Glob`, `Grep`, `Write` — read-mostly. אין Edit על תוצרים, אין Bash, אין Web, אין API.

## תיקיות

- `QA_Reports/` — לוג היסטורי של כל הדוחות, פורמט: `<YYYY-MM-DD-HHMM>-<slug>.md`

## Flow

```
CEO → גיא (path + brief + round)
     ↓
   קריאה → צ'קליסט 5 קטגוריות → דוח → ✅/❌ ל-CEO
```

**3 סבבים מקסימום.** בסבב 3 אם גיא דוחה — CEO מציג למשתמש לקבלת החלטה ידנית.
