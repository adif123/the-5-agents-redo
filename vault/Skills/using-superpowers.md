# Using Superpowers

## מה הסקיל עושה
סקיל ה-bootstrap — מגדיר את הכלל: לפני כל תגובה, בדוק אם סקיל רלוונטי ואם כן — הפעל אותו.

## מתי מפעילים
בתחילת כל שיחה. זהו הסקיל שמפעיל את כל שאר הסקילים.

## הכלל המרכזי
אם יש **1% סיכוי** שסקיל רלוונטי — מפעילים אותו. לא ניחוש, לא "זה פשוט מדי", לא "כבר יודע".

## סדר עדיפויות בין סקילים
1. **Process skills ראשון** (brainstorming, debugging) — קובעים איך לגשת למשימה
2. **Implementation skills שני** — מנחים את הביצוע

## Red Flags (מחשבות שאומרות "אל תפעיל סקיל")
- "זו שאלה פשוטה" → בדוק סקיל
- "צריך עוד context קודם" → סקיל בא לפני שאלות הבהרה
- "אני זוכר את הסקיל" → הסקילים מתעדכנים, קרא את הגרסה הנוכחית

## סקילים קשורים
- כל הסקילים האחרים — סקיל זה מפעיל אותם
