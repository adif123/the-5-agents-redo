# Verification Before Completion

## מה הסקיל עושה
מחייב הרצת פקודת אימות וקריאת הפלט לפני כל טענה שעבודה הסתיימה.

## מתי מפעילים
לפני כל הצהרה על סיום — "הטסטים עוברים", "הבאג תוקן", "הבניה הצליחה". לפני commit, PR, או מעבר למשימה הבאה.

## Iron Law
**אין טענות סיום ללא ראיות מאימות שנעשה עכשיו.**

"should work", "probably passes", "looks correct" = הפרת הכלל.

## תהליך
1. **זהה** — איזו פקודה מוכיחה את הטענה?
2. **הרץ** — הפקודה המלאה, עכשיו, מחדש
3. **קרא** — את כל הפלט, כולל exit code
4. **אמת** — האם הפלט מאשר את הטענה?
5. **רק אז** — טען שהעבודה הסתיימה
