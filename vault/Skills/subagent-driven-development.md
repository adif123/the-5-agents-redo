# Subagent-Driven Development

## מה הסקיל עושה
מבצע תכנית מימוש בסשן הנוכחי — subagent חדש לכל משימה, ואחריה שני שלבי review: עמידה ב-spec ואיכות קוד.

## מתי מפעילים
כשיש תכנית מימוש עם משימות עצמאיות וצריך לבצע אותה בסשן הנוכחי.

## תהליך בקצרה
לכל משימה:
1. שיגור subagent מממש (מקבל את טקסט המשימה המלא, לא קורא את הקובץ)
2. subagent שואל שאלות → עונים → מממש → commits
3. שיגור spec reviewer → בודק שהקוד עומד בדרישות
4. שיגור code quality reviewer → בודק איכות
5. תיקונים לפי הצורך → שלב הבא

**לא עוצרים בין משימות** — מבצעים הכל ברצף ללא אישור ביניים.
